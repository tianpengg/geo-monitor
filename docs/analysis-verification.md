## 官方身份及来源

新增 Mistral 三种、Amazon 三种和 DuckAssistBot，共 20 个 HTTP 身份。新增身份正反例和实际接收链路、独立核验、固定源格式、不同身份不借用地址证据均通过测试。MistralAI-Training 暂无已确认地址源，继续仅 UA 匹配；不回填历史记录。

2026-10-28 独立在线检查六个新增官方地址源，均 HTTP 200 且解析成功：Mistral User / Index 分别 4 / 2 条，Amazon 通用 / 搜索 / 用户请求分别 1292 / 816 / 1023 条，DuckAssistBot 486 条。此为当时在线结果，运行时仍检查证据有效性；确定性测试使用保留测试地址夹具，不把合成请求作为真实官方访问。Amazon 的 HTML JSON code 格式只对固定官方地址启用，其他来源继续要求 JSON。具体官方链接见 `docs/crawlers.md`。

## 浏览器实际流程

使用本机 Chromium、真实 FastAPI 和独立临时数据库，`tests/browser/server.py --seed` 生成受控访问。未接入生产日志。脚本、文件、截图及下载副本放在被忽略的 `output/playwright/analysis-qa/`。

- 页面排行显示 2368 次请求、126 个路径；`/docs/getting-started` 精确详情为 19 次、14 次已核验，状态分布 200 / 304 / 403 为 16 / 1 / 2，跳转明细仅含该路径的 19 条。
- 路径 `/docs/` + KimiBot + 4xx + verified 的第二页为 3 条；CSV 下载 23 条，证明导出全部匹配而非当前页。最终版本全量 CSV 下载 2368 条，包含规则、归属及证据来源、版本和时间，不包含原始 IP、UA、查询参数或凭据。
- 实际 30 秒定时更新后，第二页及四个组合条件保持，最后更新时间推进；没有模拟刷新时钟。
- JSON 导入 4 页，CSV 合并新增 1 / 更新 1，XML 再新增 1：6 页中观察 3、未观察 3，比例 50%。外站文件明确拒绝且目录保持 6 页；目录移除后为 5 页、观察 3、未观察 2、比例 60%，访问事实未删除。最终预览重建后重新导入六页作为演示。
- 未观察页面详情显示 0 请求和最近访问暂无，保留所选日期与观察说明；不是“从未抓取”。真实插入隔离测试缺口后界面显示缺口及不完整说明；近 30 天同时说明包含首次启用前时段。测试缺口已移除。
- 浏览器临时离线后，旧目录统计保留，显示更新失败及最后成功时间；恢复联网重试成功。网络模拟已恢复。
- 给 API 加 1200 ms 临时延迟，在页面分析加载时退出；迟到响应没有恢复页面，受保护表格数为 0。重新登录后新增筛选全部清空。网络延迟已恢复。
- 在窄屏完成目录选择、移除及未观察页面详情；对 CSS 320、390、768、1280 宽度记录的文档 clientWidth / scrollWidth 分别为 308 / 308、378 / 378、756 / 756、1268 / 1268，无页面横向溢出。桌面与窄屏覆盖按钮、筛选、长路径、响应与核验字段。

预期的无效导入 400、会话变更 401 及临时离线网络错误单独保留；未观察到未处理的应用 JavaScript 异常。浏览器原有缩放下高层截图接口曾发生裁切，最终使用原始页面截图重新保存完整画面，没有为修饰结果修改业务 DOM。响应式视口和网络模拟在验收后恢复。
