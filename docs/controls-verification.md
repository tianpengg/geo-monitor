# 自定义表单控件验收

日期：2026-10-28。变更：`refine-form-controls`，归档位置 `openspec/changes/archive/2026-10-28-refine-form-controls/`。沿用现有浅色靛蓝卡片设计，正式规范 `admin-dashboard-interface` 增加统一表单要求，能力规范仍为 12 组。

## 实现范围

- 共用输入框支持图标、清空、只读多行、密码显示与隐藏，保留原生输入语义和自动填充属性。
- 自定义下拉支持搜索、选中和无结果状态、方向键、Enter、Escape、Tab；状态码仍允许手动填写完整代码或类别。
- 自定义日历支持 ISO 日期输入、月份导航、六周网格、方向键与 PageUp / PageDown、今天和清空。今天在每次打开时按官网时区计算，严格拒绝不存在的日期、半个范围或倒置范围。
- 文件选择区显示格式、名称、大小、重选和移除，支持拖放入口；隐藏文件 input 只负责唤起系统文件对话框，页面不显示系统文件按钮。原有 UTF-8、格式和容量检查仍由导入流程执行。
- 共用浮层独立于卡片裁切区，处理屏幕边界、外部点击、Escape、焦点及禁用状态。折叠说明使用统一图标，保留原生 details 语义。

控件只更新筛选草稿，点击查询后才提交；没有改变认证、查询参数、服务端统计或核验口径，没有新增生产依赖。

## 隔离浏览器检查

使用仅监听 `127.0.0.1:8018` 的验证服务、合成种子和临时 SQLite 数据库，未接入真实官网。通过 CUA 操作实际 Vue 与 API，结果如下：

1. 登录：空表单显示自定义必填提示；密码显示与隐藏有效；实际登录成功。
2. 下拉：搜索 `KimiBot` 返回对应身份；不存在的词显示无结果；方向键与 Enter 选中并关闭，焦点返回触发器；Escape、Tab 和点击外部关闭正常，Tab 继续进入下个输入框。
3. 筛选：手动输入 418 可查询为空；选择 4xx 后显示对应 403 记录，未改变状态码查询能力。
4. 日历：月份与键盘日期导航有效；选择 2026-10-22 回填相同 ISO 值；清空有效；2026-02-30 被自定义错误提示拒绝，不使用浏览器日期面板。
5. 配置：自定义客户端 IP 下拉保留原值，官网保存成功；配置输入保持原有 API 验证。
6. 目录：通过自定义“选择文件”按钮选择合成 JSON，显示文件名称及大小；实际合并导入成功（新增 0、更新 4、目录总计 6）；移除选中文件恢复初始提示。未单独执行操作系统拖放动作。
7. 小屏：416 px 日历完整显示；320 × 844 下右侧日期弹层左 12、右 308、上约 365、下约 734，核验下拉左 78、右 308、下约 718，均在视口内，无页面水平溢出。Escape 后焦点返回结束日期。测试后已恢复正常视口。

视觉检查确认输入边框、焦点、下拉搜索、列表阴影、日历选中状态和文件区与既有卡片风格一致。检查中发现弹层首次打开搜索框未自动获得焦点，已在定位样式完成渲染后再触发聚焦，并回归搜索、Tab 和 Escape；没有遗留的本次阻塞问题。
