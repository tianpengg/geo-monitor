## 功能与故障恢复

- 管理员登录、错误凭据、退出后会话失效、CSRF 和来源检查；采集凭据不能访问管理接口。
- 单官网配置、稳定网站/来源标识、只保存采集凭据校验值、后续查询不回显完整凭据。
- Combined 解析、转义、IPv4/IPv6、非成功状态、查询参数移除及合成样本。
- 首次 EOF 基线、完整行和半行、多字节路径的字节偏移、过长/损坏行后继续采集。
- 断网与响应丢失不推进确认位置，进程重启恢复；后台已提交但响应丢失后重传不重复计数。
- 重命名新建轮转、多次离线轮转、截断与可恢复副本、已知缺口；正常清理完全确认的轮转文件不误报缺口。
- 数据库事务中途失败整体回滚；过期明细重传不复活记录；一致备份可恢复并通过 SQLite integrity_check。
- 13 个 UA 规则及对应官方证据核验；有效、过期、不可用、不匹配、客户端地址未知的独立表达；共用地址每轮抓取一次。
- 持久化记录、采集状态和校验响应不保留原始客户端 IP 或完整原始日志；未知线索有数量和字段限制。
- 跨日与统计时区、今天/近 7/近 30 天、组合筛选、稳定分页、不同路径数及核验分布。
- 独立心跳、安静来源、普通访问没有爬虫、积压、读错误、断连与缺口；安装前时段不补零。

集成测试实际启动独立服务端及采集器进程，通过本机 HTTP 连接，向临时源文件追加合成 Combined 行，验证自动到达及 60 秒目标。输入是受控样本，不是已观测到的真实平台爬虫访问，也不替代 Linux / 宝塔容器环境验收。

## 浏览器功能验证

使用 Playwright CLI、临时数据库及仅监听 127.0.0.1 的验证服务，未接入真实官网。

- 通过浏览器完成登录、官网保存、客户端地址口径选择、凭据生成和安装命令展示。
- 真实运行的临时采集器保持心跳，页面显示采集正常与“未观察到可识别的 AI 爬虫访问”。
- 向临时日志追加一条请求后，自动在后台看到路径 `/browser-verified-visit`、GET、403、Kimi 声明身份及独立核验状态，查询参数不展示。
- 组合日期及爬虫筛选有效，筛选无记录时保留健康说明。
- 停止临时采集器后，页面明确显示断连及最后心跳、最后数据时间；测试服务缩短断连阈值以验证展示，生产默认阈值另由受控时间测试验证为 90 秒。
- 对临时来源发送受控健康消息，确认积压字节、读取异常及已知缺口的呈现。这部分验证页面渲染；实际文件故障的采集行为由集成测试独立覆盖。
- 退出后回到登录状态。页面只含功能结构，不作为最终视觉设计交付。
