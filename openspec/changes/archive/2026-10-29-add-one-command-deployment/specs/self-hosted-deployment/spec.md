# Spec Delta

## ADDED Requirements

### Requirement: 一条命令部署控制台
项目 SHALL 提供 Linux Shell 部署入口，从完整源码检查 Docker 与 Compose，收集或读取后台地址、管理员凭据和端口，生成受限权限配置并启动控制台。新配置须使用 HTTPS、Secure Cookie 和本机端口绑定；密码不得进入命令行参数或终端输出。既有配置不得被静默覆盖，重复部署保持原数据卷；仅在健康检查通过后报告成功，失败返回非零状态。

#### Scenario: 首次部署
- **WHEN** 管理员运行脚本并提供有效参数
- **THEN** 配置以 0600 权限保存，密码特殊字符保持原值，控制台构建启动并经健康检查后输出后台地址和 1Panel 配置步骤

#### Scenario: 重复执行与失败
- **WHEN** 配置已存在或 Docker、配置、构建及健康检查失败
- **THEN** 既有配置和数据卷不被删除或替换，重复执行复用原值；失败清晰退出且不将密码输出到诊断信息

#### Scenario: 采集器入口
- **WHEN** 管理员选择采集器安装模式并提供后台及来源标识
- **THEN** 入口调用已有 HTTPS 安装流程，日志路径及采集凭据按原流程输入，不自动修改网站证书、代理或日志
