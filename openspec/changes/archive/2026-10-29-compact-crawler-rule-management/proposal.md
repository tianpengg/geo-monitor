# Proposal

## Why

当前规则列表与编辑器并排常驻，规则较多时列表过长，编辑器持续占据页面宽度。管理员希望集中查看表格，仅在新增或修改时打开弹窗。

## What Changes

- 规则以紧凑表格展示，保留搜索、启停、证据刷新及真实状态。
- 新增与编辑改为弹窗，保存成功关闭，验证失败保留草稿并在弹窗内提示。
- 弹窗支持取消、关闭、Escape、焦点约束及返回触发按钮；适配既有自定义下拉与手机内部滚动。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `admin-dashboard-interface`: 规则表格、弹窗编辑与可访问操作。

## Impact

仅调整 Vue 页面、规则编辑状态和共用弹窗，更新说明及前端 / 浏览器验证。不改后端接口、识别规则或数据结构，不增加生产依赖。既有 HTTP / Docker 未验收边界保持不变。
