## ADDED Requirements

### Requirement: 可选 HTTP 或 HTTPS 上报

采集器安装 SHALL 接受无凭据、无子路径的 HTTP 或 HTTPS 后台地址，按所选协议下载并生成可运行配置；选择 HTTP 须显式允许 HTTP 上报并显示明文传输提示，选择 HTTPS 须校验证书且下载不得降级至 HTTP。安装命令不得内嵌采集凭据，日志只读、独立心跳、确认位置及重连语义保持一致。

#### Scenario: HTTP 安装与采集
- **WHEN** 管理员使用 HTTP 后台地址执行安装并提供有效标识、凭据和日志路径
- **THEN** 无需证书即可下载、预检、启动和上报新增日志及心跳，配置以受限权限显式允许 HTTP，后台能查询记录，停止重连后读取位置保留

#### Scenario: HTTPS 安装与校验
- **WHEN** 管理员使用 HTTPS 地址执行安装
- **THEN** 下载和上报均验证证书，不使用跳过校验选项，下载重定向至 HTTP 时失败且不报告成功

#### Scenario: 无效地址或未允许 HTTP
- **WHEN** 安装地址使用其他协议、携带凭据或子路径，或手工 HTTP 采集配置未显式允许 HTTP
- **THEN** 安装或配置加载明确失败，不输出凭据且不推进已有采集位置
