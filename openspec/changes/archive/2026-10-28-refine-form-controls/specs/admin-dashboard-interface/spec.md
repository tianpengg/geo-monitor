# Spec Delta

## ADDED Requirements

### Requirement: 统一自定义表单控件
后台 SHALL 使用与浅色靛蓝视觉一致的自定义输入、下拉、日期及文件选择区，不显示原生 select、datalist、日期面板或文件按钮；保留认证、筛选、表单验证和导入能力。弹层应避让屏幕边界，支持外部点击关闭、Escape 和合理焦点恢复，禁用时不可修改，鼠标与键盘均可完成操作。

#### Scenario: 搜索下拉并选择
- **WHEN** 管理员打开爬虫下拉、输入搜索并使用方向键和 Enter
- **THEN** 自定义列表更新，展示选中状态和无结果提示，选择后关闭并更新筛选草稿，不提前查询

#### Scenario: 日期输入与选择
- **WHEN** 管理员通过日历或手动输入设置日期
- **THEN** 草稿保持 ISO 日期，日历支持月份导航及清空，今天按官网时区计算，无效日期和倒置范围仍被拒绝

#### Scenario: 文件选择及表单状态
- **WHEN** 管理员选择或拖入目录文件，或使用登录及官网配置表单
- **THEN** 文件区显示名称、大小和移除入口，输入提供一致焦点与禁用状态，密码自动填充和必填验证继续可用
