# Proposal

## Why

官网主域名与 Sitemap 页面中的 www 域名可能指向同一站点，当前严格同主机校验会拒绝整份目录。需要让管理员明确登记同站别名，避免为导入清单修改官网地址，同时保留下载和历史目录隔离。

## What Changes

- 官网配置增加最多 10 个精确域名别名，默认空；标准化、去重，拒绝通配符、IP、协议和路径。
- 远程 Sitemap 地址、单层索引及页面地址、本地目录导入接受主域名或已保存别名；同路径合并到当前官网目录。
- 每个实际下载主机独立执行公网 DNS、固定 IP 与证书校验，继续拒绝跳转和未登记域名，不抓取页面正文。
- 别名更新失效旧同步任务，并为已启用配置重新排队；删除别名不删除已有目录。旧客户端省略字段时保留同主域的别名，切换主域且省略时清空。
- 使用现有官网表单和控件提供别名输入、用途说明及 Sitemap 提示；退出和迟到响应不恢复草稿。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `admin-site-configuration`：明确登记当前官网别名并保持单站身份及兼容迁移。
- `content-inventory`：按允许域名清单接受并合并目录，别名变化后的旧任务不提交。
- `admin-dashboard-interface`：官网别名输入及清单允许范围说明。

## Impact

增加 site 表的 JSON 别名字段；调整官网 API、目录解析、Sitemap 调度和受限下载的目标主机传递，以及 Vue 类型、表单和状态管理。不改变采集器、凭据、源日志、统计口径或生产站点配置，不增加依赖。
