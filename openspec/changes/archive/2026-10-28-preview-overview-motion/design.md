# Design

## Context

用户已提供选定的浅色首页截图，并要求重绘卡通和动画特效、生成 HTML 查看。首轮预览后，用户要求更精致的卡片、明确的视觉主次，并在查看竞品研究后确认按 Dub 的浅色视觉、OpenPanel 的信息层级重做。该请求授权独立预览实现，正式 Vue 页面和后台不在本轮范围。

## Goals / Non-Goals

- 沿用浅色靛蓝方向，参考真实产品重新组织桌面卡片，并为窄屏调整阅读顺序。
- 使用真实透明精灵素材；Canvas 只绘制用户要求的实时轨道、粒子和扫描特效，以及数据图表。
- 单文件 HTML 可离线运行，提供演示范围切换、明细和放大动效检查。
- 不接入实际采集、身份认证、接口或通知告警，不修改现有 API。

## Decisions

- 文件位于 `web/prototypes/overview-motion/`，通过标准库构建脚本将本地图片、字体和 MIT Tabler 图标嵌入最终 HTML；不引入框架或远程运行依赖。
- 原截图约束浅色靛蓝、内容范围与精灵方向；最新用户确认的竞品参考优先决定布局。Dub 公开面板参考：<https://app.dub.co/share/dash_6NSA6vNm017MZwfzt8SubNSZ>；OpenPanel 公开面板参考：<https://demo.openpanel.dev/demo/shoey>。参考截图位于忽略的 `output/playwright/design-research/`。
- 采用灰白画布、白色卡片、接近黑色的标题与数字；靛蓝用于数据和选中项，语义色只表达健康、积压、异常。四张指标卡展示识别请求、核验请求、页面与活跃爬虫；宽趋势卡与独立健康卡构成视觉中心，下方展示排行和近期明细。通过排版、间距、边框和轻阴影建立主次。
- 采集健康卡结合精灵、明确的状态文字、最后心跳与数据时间，以及积压、解析异常和缺口数量。动画辅助解释状态，不能替代文字或表示真实流量；所有数据与状态切换明确为演示。
- 素材为 2×2 透明姿态图，包含睁眼、眨眼、扫描及休眠姿态。运行时通过画布裁切实际素材，身体悬浮与轨道按同一动画时钟绘制，避免暂停不一致。
- 轨道使用前后半椭圆分层，与卫星、轻轨迹及扫光同步。正常轻扫描、补采加速、断连静止并降饱和；状态切换仅为演示。
- 动效放大使用原生 dialog，支持暂停、重播、状态切换、键盘和焦点恢复；尊重 reduced-motion，页面隐藏时取消 animation frame。
- 演示默认沿用 2026-10-28 的受控样本；近七天的 2368 条统计与趋势点一致，不声称实时生产观测。

## Risks / Trade-offs

- AI 素材可能出现帧位置差异：检查实际尺寸和姿态，必要时仅调整素材显示参数，不以绘制假图替代。
- 中文采用系统可用的黑体字体，Inter 内嵌用于西文和数字；保证字号、行高、字重和布局一致，记录不同平台字体的细微差异。
- 独立 HTML 内嵌图片体积大于外链：以离线完整交付和直接打开优先。

## Validation

- 在桌面与手机宽度检查布局、溢出和可操作性。
- 检查日期切换、明细、dialog、暂停/重播、三种状态、键盘、减少动态效果及控制台错误。
- 将实际浏览器截图与参考图放入同一对照输入，记录 `design-qa.md`；修复本轮 P0/P1/P2 后交付。
