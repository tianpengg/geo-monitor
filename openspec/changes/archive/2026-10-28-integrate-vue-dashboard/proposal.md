# Proposal

## Why

用户已确认取消动画人物的浅色首页，并要求实现到正式 Vue 后台。当前后台只有基础功能排版，需要在保留完整管理流程和真实数据口径的前提下，将已确认设计变成可使用的管理界面。

## What Changes

- 将灰白画布、靛蓝数据、侧栏和卡片布局接入现有 Vue 应用，统一登录、配置、概览、明细及健康页面。
- 概览展示真实指标、覆盖感知的趋势、爬虫排行和近期访问；健康区域使用纯数据卡。
- 保留日期与爬虫筛选、分页、核验依据、安装凭据和登录会话，补齐加载、空白、失败和过期状态。
- 按原约定自动刷新并保留筛选；清楚区分无访问、未观测和采集异常。

## Capabilities

### New Capabilities

- `admin-dashboard-interface`：正式 Vue 管理界面的导航、卡片表现、真实数据、加载失败及响应式交互。

### Modified Capabilities

无。复用现有业务、API、时间、来源核验与健康判断规范。

## Impact

影响 `web/src/`、前端测试、浏览器验收夹具及相关说明；复用本地图标和字体。保留独立 HTML 作为视觉参考，不引入图表框架、路由框架或新的生产依赖。
