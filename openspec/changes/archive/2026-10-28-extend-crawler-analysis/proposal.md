# Proposal

## Why

现有首版已完成采集与访问观察闭环，但管理员仍难以按页面分析、定位特定响应和比较重要内容的观测情况。用户选择先完整开发专注的爬虫监测能力，再统一接入真实官网验收。

## What Changes

- 新增页面排行和单页面详情，复用真实请求、核验和日期口径。
- 明细增加路径搜索、精确页面、状态码和核验筛选，并按同一条件导出有界 CSV。
- 增加经官方资料确认的 Mistral、Amazon 和 DuckDuckGo 请求身份；规则随代码发布，保留独立来源核验及历史证据。
- 支持本地 sitemap XML、CSV、JSON 内容目录合并导入、列表及移除，展示指定范围内已观察与未观察的页面及覆盖限制。
- Vue 沿用浅色卡片，完成所有功能的隔离联调；生产接入与真实负载验收在部署时执行。
- 继续单管理员、单官网和单日志来源；不引入团队、CDN、访客转化、评分、AI 辅助或访问控制。

## Capabilities

### New Capabilities

- `page-analytics`：页面排行、详情、请求分布与筛选一致性。
- `content-inventory`：有界内容目录导入、管理、观察覆盖及缺失输入说明。

### Modified Capabilities

- `traffic-details`：路径、状态与核验筛选及同条件 CSV 导出。
- `crawler-identification`：扩展经过官方确认的身份，展示规则版本及依据。
- `admin-dashboard-interface`：新增页面分析与内容目录界面，保留刷新、认证、响应式及失败一致性。

## Impact

涉及 SQLite 追加迁移、服务端查询与内容目录模块、API、规则及证据解析兼容、Vue 组件、测试和部署说明。保持采集协议、去重位置和既有统计不变；使用标准库解析本地文件，不主动访问用户提交的 URL，不新增生产依赖。
