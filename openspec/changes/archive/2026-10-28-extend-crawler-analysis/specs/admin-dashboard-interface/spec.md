# Spec Delta

## ADDED Requirements

### Requirement: 页面分析与内容目录操作
后台 SHALL 在既有浅色界面提供页面分析和内容目录导航，支持排行、页面详情、同条件明细、目录导入及观察筛选；日期与新增筛选在刷新时保留，退出与旧响应防护适用于新增数据。加载、失败、未配置目录和未观察记录分别表达，桌面和手机均可操作。

#### Scenario: 手机导入后查看未观察页面
- **WHEN** 管理员在手机选择本地目录文件并导入，然后选择未观察筛选
- **THEN** 导入结果明确显示，列表与目录指标正确更新，页面路径和覆盖限制可读，且能够打开对应页面分析
