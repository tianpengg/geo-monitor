# Design

## Context

现有 events 已保存规范路径、身份、核验、状态及事件时间，查询接口有日期和稳定游标。数据库当前一版迁移，Vue 无路由库，正式界面已采用浅色卡片。动机和功能边界见 proposal.md。

## Goals / Non-Goals

保留现有单站与隐私边界，完整实现约定增强功能。目录只是管理员提供的已知集合，不声称穷举官网；不开发远程 sitemap 抓取、浏览器流量追踪或规则后台发布。

## Decisions

- 抽取共用日期和事件过滤器，参数化 SQL 并转义 LIKE 通配符。明细、页面聚合、详情及导出复用；请求排序使用时间及事件 ID，排行以请求数及路径稳定排序，目录按路径排序。有界 offset 页面允许新增数据使排行变化，界面显示刷新，不承诺跨刷新快照游标。
- 增加 events(site_id,path,occurred_at) 索引及 content_pages(site_id,host,path,title,imported_at) 追加迁移；不改既有迁移。目录绑定导入主机，域名修改后不混用。导入同路径更新标题，合并事务最多 10000 条。
- 本地导入用 UTF-8 JSON 文本接口承载 1 MiB 文件，不增加 multipart 依赖。XML 仅 urlset，拒绝 DTD、实体和 index；CSV 使用 path 或 url 及可选 title；JSON 为字符串或带 path/url/title 对象的数组。完整校验后写入，不输出原始文件片段，不主动联网。路径保留编码与尾斜杠，去查询和片段，排除外站、凭据、反斜杠及非标准端口。
- 页面详情复用趋势断点与健康快照；目录比较返回明确的 coverage 状态与说明。安装前、未来、保留期外或异常范围保守标为未观测或部分观测；现有缺口无精确时间边界时保守标记整段受限。分母为当前主机已导入目录，在所选搜索条件下统计，身份和响应过滤决定分子。
- CSV 在读取事务内按当前过滤条件取最多 10001 条，超 10000 条或编码后 20 MiB 则拒绝；UTF-8 BOM 支持中文，固定文件名、单元格公式转义，附时区与源站口径列。浏览器认证下载不带游标，复用失败和 401 清理。
- 新增 7 个官方身份，Mistral 训练身份无已确认地址源时只做 UA 识别；分别绑定可验证的官方 JSON 地址，不交叉借用。规则版本更新，保留历史入库事件及证据。
- 官方格式核对发现 Amazon 三个地址源以 HTML code 块承载 JSON，固定 Amazon 来源启用严格的单 code 候选解析，兼容其中的 ip_prefix 字段；其他来源仍要求 JSON。原始字段及解析夹具分别测试，不将任意 HTML 作为证据。
- Vue 新增 PagesPanel 和 InventoryPanel；日期及筛选由 App 管理，新增页签按需取数据，刷新序号防止过时结果覆盖。保留原来概览不受明细条件影响的行为；文件内容和下载 Blob 不持久保存，退出清理新增数据。

## Risks / Trade-offs

- 日志只有保留的请求事实 → 明确 30 天保留窗口及观测限制，不称未抓取。
- 大目录或导出 → 输入、总量、分页和输出上限，错误整体拒绝，测试边界和原子性。
- 官方来源格式变化 → 固定官方依据、夹具回归、未知或失效不标为核验成功。
- 当前演示服务为旧进程 → 完成构建后以新的隔离临时数据库展示，保留真实生产未接入的边界。

## Migration Plan

启动时事务追加迁移，可从一版数据库无损升级并重复启动；升级前按现有 backup API 备份。旧程序拒绝新版 schema，回退须恢复升级前一致备份，不能删除新目录表伪装兼容。验收包含迁移、旧事实保留、完整接口与浏览器及容器基础冒烟；不因业务 UI 增强重复无关的完整采集故障矩阵。
