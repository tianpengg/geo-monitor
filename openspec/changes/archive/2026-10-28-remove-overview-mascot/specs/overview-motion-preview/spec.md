# Spec Delta

## MODIFIED Requirements

### Requirement: 独立 HTML 与演示边界

预览 SHALL 以无外部网络依赖的 HTML 交付，采用用户确认的浅色卡片方向，提供统计、趋势、采集健康、排行及最近访问，并明确标注演示数据；不得连接真实后台或改变既有业务。

#### Scenario: 直接打开预览
- **WHEN** 用户直接打开交付的 HTML 文件
- **THEN** 页面、图表和交互完整可用，无需安装依赖或连接互联网，页面不包含动画人物及其动效控制

### Requirement: 动效可访问性

预览 SHALL 尊重减少动态效果偏好，在页面不可见时停止数字过渡；访问明细等弹窗支持键盘打开、Escape 关闭及焦点返回。

#### Scenario: 减少动态效果
- **WHEN** 浏览器请求减少动态效果
- **THEN** 日期切换直接展示最终数字，不播放数字过渡

#### Scenario: 键盘关闭
- **WHEN** 用户通过键盘进入访问明细后按 Escape
- **THEN** 明细关闭且焦点回到触发按钮

## ADDED Requirements

### Requirement: 纯数据采集健康卡

预览 SHALL 使用状态文字、链路检查、最后心跳、最后日志时间、待确认量、解析异常及已知缺口展示采集健康；支持正常、补采和断连演示，导航可直接定位健康卡。

#### Scenario: 切换采集状态
- **WHEN** 用户在健康卡选择正常、补采或断连演示状态
- **THEN** 状态、说明和待确认量同步变化，断连保留最后时间，不显示采集正常或推定永久丢失

#### Scenario: 定位健康卡
- **WHEN** 用户点击采集健康导航
- **THEN** 页面滚动并聚焦健康数据卡，不打开人物或动效弹窗

## REMOVED Requirements

### Requirement: 重绘精灵与实际动效

**Reason**: 用户明确取消动画人物。
**Migration**: 采集健康改为纯数据卡，移除人物、轨道、扫描、放大、暂停及重播。
