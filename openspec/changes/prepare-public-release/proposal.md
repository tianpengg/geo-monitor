# Proposal

## Why

项目准备首次公开到用户指定的 GitHub 账号，用户已选择 MIT。当前缺少项目许可证，首页偏向开发历史，部分说明含真实部署信息；采集器分发白名单和镜像也需要保留许可文本。

## What Changes

- 增加 MIT、第三方素材许可说明、贡献指南、安全反馈入口与 Issue / PR 模板。
- README 面向使用者说明能力、识别边界、部署、采集接入和验证；1Panel 指引改为通用示例，对公开文档脱敏。
- 在源码、Python 包、镜像和采集器下载包中保留项目许可，不分发实际配置与运行数据。
- 检查待提交文件，确认目标 GitHub 账号后创建或使用公开仓库、提交并推送，记录实际结果和待验事项。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `self-hosted-deployment`：公开交付与许可保留要求。

## Impact

涉及 README、社区文档、发布元数据、Dockerfile、采集器下载白名单及相关回归。无协议、数据库、采集和统计逻辑变更；既有容器专项待验任务不变。首次提交前无历史提交需要清理，不改写已有远程历史，不上传旧部署 ZIP 或本地数据库。
